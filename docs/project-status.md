## 阅读时应采用的修正

- “参数普遍不保存”的早期判断已被复测撤回。
- `SUM=` 是段体逐字节累加；软件解码的统计/结构支持不能代替 SoC 硬件解码或运行内存对照。
- FIRM / BOOT 回退的早期描述已收窄：内层解码错误被吞掉，不能期待自动恢复。先读 [较新的打包链复核](../reports/repack-pipeline-2026-10-27.md)，再读 [升级恢复调查](../reports/update-recovery-path-2026-10-27.md)。
- 106 个 Unicorn 命令边界用例不是整机稳定性验证，也未证明该问题造成日常挂死。
- 真机对照支持 P/A/S 已有曝光补偿预览；M 档候选尚未完成真机验证。
- 全量导出的 27,107 个函数和 107,849 条字符串，不代表已全部通读或语义正确。
- USB 存储掉线不等于整机挂死；国际版工具的结论也不能直接推广到 CN 固件。
