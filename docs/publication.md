# 公开范围与脱敏说明

此仓库从本地研究文件快照建立独立 Git 历史，不包含原项目的提交历史。

保留：分析与校验脚本、实验源码、合成测试、地址清单、研究文档、固件哈希和脱敏的数值结果。

排除与替换：

- 私人会话和代理交接记录由技术状态摘要替代。
- 本机用户名、个人绝对路径和设备序列号已替换；命令使用 `python` 与项目相对路径。
- 不提交照片、取景画面、原始网络包、原始日志、SD 内容及文件系统检查记录。
- 不提交官方/实验固件、第三方安装目录、Ghidra 数据库、全量反编译输出、缓存和临时文件。
- 本机生成的 `reports/toolchain-installed.json` 已排除提交。

保留相机协议默认地址、USB VID/PID、固件哈希、函数地址等通用研究信息；硬件唯一序列号已脱敏。历史报告中未分发的本地产物需要重新生成。

发布前对公开文件与全部公开提交使用 [Gitleaks](https://github.com/gitleaks/gitleaks) 检查密钥，并检查个人路径、设备标识、文件清单和 Git 作者。自动扫描不能代替隐私复核。后续分享 JSON、日志或图片也应先脱敏；`.gitignore` 不能清除已经提交的内容。
